# MPR First Finalist Program V1

## Objective
Produce the first **real, legitimate FINALIST** using evidence that passes every gate. No score, lower bound, supplier listing, estimate or missing value may be promoted into stronger evidence.

## Operating ratio
Until the first legitimate FINALIST: **20% build / 80% real data acquisition and validation**.

## Eight program KPIs
1. Products with >=2 live public snapshots at eligible interval.
2. Products with confirmed fused longitudinal trend (rank + reviews).
3. Niches with exact comparable Romania Gap evidence.
4. Products with a verified supplier package.
5. Products with confirmed landed economics.
6. PROMISING products.
7. VALIDATE products.
8. FINALIST products.

## Ordered execution
### Phase A — Longitudinal Amazon data
- Complete Round 2 only after each observation is >=24h old.
- Preserve review and price movement as public observation evidence.
- Do not infer rank from product-page order.
- Do not infer verified sales from reviews or rank.

### Phase B — Public ranking history + Trend Fusion
- Collect explicit Amazon Best Sellers ranking snapshots separately.
- Rank velocity requires two explicit ranks at >=24h.
- Confirm acceleration only through the strict rank + review fusion contract.
- Review-only or rank-only evidence is maximum PROMISING support.

### Phase C — First exact Romania Gap
- Prove one niche before scaling local coverage.
- Require direct eMAG + Trendyol observations in the canonical ledger.
- Require manual review, MARKET_WIDE comparable scope, same canonical comparability key and exact counts.
- Sampled/surface counts remain preliminary and maximum PROMISING support.

### Phase D — Supplier verification
For the first VALIDATE product obtain >=3 complete comparable quotes including exact product identity, MOQ, unit price, Romania shipping/DDP, lead time, sample terms and compliance evidence. At least one package must be MANUALLY_VERIFIED before supplier gate passes.

### Phase E — Confirmed economics
Confirm landed cost from real quote evidence and complete FX/freight/duty/tax/compliance inputs. Then calculate profit/unit, margin, ROI and break-even. Missing values remain unknown, never zero.

### Phase F — First FINALIST
Rerun Opportunity V4. FINALIST requires simultaneously:
- confirmed longitudinal trend fusion;
- exact comparable Romania evidence;
- verified supplier;
- confirmed economics.

Maximum 3 FINALIST. FINALIST and TEST_READY never authorize purchase.

### Phase G — First TEST_READY and measured test
After compliance/test gates pass, prepare a controlled 20–30 unit test. A real order or purchase requires explicit human action and is outside automatic decision authority. Feed measured results back into calibration only after the test actually occurs.

### Phase H — Scale breadth
Major catalogue expansion begins only after the first legitimate FINALIST proves the evidence path. Scale staged: 1K → 10K → 50K → 100K → 500K → 1M.

## Execution rule
The program advances on evidence, not code volume. Every completed batch must refresh the First Finalist Program report and identify the next blocker.

## Safety
- no paid provider call without explicit approval;
- no automatic purchase;
- unknown != zero;
- ranking != verified sales;
- review growth != verified sales;
- sampled Romania != exact competition;
- supplier listing != verified quote;
- verified quote != confirmed landed cost.
