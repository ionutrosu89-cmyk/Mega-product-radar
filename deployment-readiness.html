Interpretare

SANDBOX GO cere configurația Stripe Test Mode, runtime DB complet și workspace sandbox curat. Billing E2E current deploy GO cere toate cele șase stări Stripe/Supabase capturate server-side pentru release-ul curent. Release prerequisites READY cere billing LIVE + runtime DB + legal P0. Public Commercial GO rămâne separat și cere toate verificările finale din checklist.

Fail-safe: un deploy cu migrare Supabase lipsă, ledger E2E incomplet, workspace deja plătit sau abonament Stripe activ rezidual rămâne NO-GO chiar dacă alte configurații sunt corecte.
