Cum se interpretează verdictul

SANDBOX GO

Toate cheile/prețurile tehnice sunt valide și cheia Stripe este de test. Poți rula fluxul FREE → Discover → Radar → Launch → anulare fără bani reali.

LIVE BILLING GO

Backend-ul confirmă cheie Stripe LIVE plus toate prețurile recurente corecte. Acest verdict înseamnă doar că infrastructura de billing este pregătită tehnic.

PUBLIC COMMERCIAL GO

Nu este acordat de această pagină. Necesită și P0 juridic închis, politica de anulare/refund/support finalizată și testul end-to-end trecut.

Fail-safe: SANDBOX nu mai poate fi afișat ca un „GO” generic pentru bani reali. Dacă Stripe nu este explicit LIVE, indicatorul Live billing rămâne NO-GO.

Ordinea corectă de setup

1. Stripe Test Mode

Creează 3 prețuri recurente lunare în EUR: Discover €17,90, Radar €29, Launch €89.

2. Netlify Environment Variables

Adaugă STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, cele 3 Price IDs, SUPABASE_SERVICE_ROLE_KEY și BETA_ANALYTICS_ADMIN_EMAILS. Nu salva secretele în GitHub.

3. Stripe Webhook

Configurează endpoint-ul de webhook către ruta aplicației și folosește signing secret-ul rezultat ca STRIPE_WEBHOOK_SECRET.

4. Sandbox cap-coadă

FREE → Discover → Radar → Launch → anulare. Confirmă că nu apar abonamente duplicate și că entitlement-ul urmează statusul Stripe.

5. Închide P0 juridic

Identitatea operatorului, contactul oficial, anularea/refundul și modelul comercial trebuie finalizate înainte de bani reali.

6. Comută controlat pe LIVE

Înlocuiește cheile și Price IDs cu variante LIVE, rerulează diagnosticul și cere explicit Live billing GO.
