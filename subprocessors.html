Furnizori tehnici actuali

Supabase

Rol: autentificare, baza de date, workspace cloud si infrastructura asociata. Date: cont, identificatori, date operationale introduse in workspace. Configuratia proiectului foloseste o regiune UE.

GitHub / GitHub Pages

Rol: cod sursa, CI/CD si gazduirea frontendului static. Continutul public al aplicatiei este livrat prin GitHub Pages; datele operationale autentificate sunt stocate in Supabase, nu in repository.

esm.sh

Rol: livrare in browser a bibliotecii Supabase JavaScript. Poate primi date tehnice de retea necesare livrarii resursei, conform propriilor politici.

Inainte de lansarea comerciala

Trebuie arhivate/verificate DPA-urile si conditiile furnizorilor, regiunile de procesare, mecanismele de transfer international si lista lor de subprocesatori. Orice furnizor nou de plati, email transactional, analytics, suport sau erori trebuie adaugat aici inainte de activare.
